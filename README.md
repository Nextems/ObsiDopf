# ObsiDopf

Настольный редактор PDF и DOCX с локальным распознаванием текста. Открывай документы во вкладках, добавляй комментарии к PDF, редактируй DOCX и копируй текст с фотографий и сканов. Интерфейс — в тёмной графитовой гамме с фиолетовыми акцентами, в стиле Obsidian.

Кандидат следующего релиза — **1.1.0**. Изменения, требования к установке и состояние подготовки описаны в [RELEASE-NOTES.md](RELEASE-NOTES.md).

## Возможности

- Перестановка вкладок мышью с плавным сдвигом соседних вкладок. При переносе к краю полоса прокручивается; колесо прокручивает длинный ряд вкладок, `Esc` отменяет перенос.
- Кнопка § вместо верхнего логотипа слева открывает тёмное окно «Лицензии и исходники»: авторство, AGPL, лицензии компонентов, поиск по списку, копирование текста и ссылки на исходники. Кнопки открытия документов сохранены.
- Кнопка ▤ слева открывает историю файлов в той же боковой области, что и чат Gemini: панели заменяют друг друга, содержимое чата сохраняется. История хранится между запусками в `%LOCALAPPDATA%\ObsidianDocs\recent-files.json`; повторное открытие поднимает файл наверх без дубликатов. Есть поиск по имени/пути, удаление записи и очистка истории. Записи не удаляют сами документы; недоступные пути остаются в списке. Несохранённые новые DOCX в историю не попадают, сохранённые — попадают после выбора имени.
- Просмотр PDF с непрерывной прокруткой, масштабированием и миниатюрами страниц справа.
- Скользящее окно PDF: текущая страница и по 15 страниц до и после неё. Диапазон прокрутки сдвигается с сохранением места просмотра; соседние страницы предзагружаются в фоне. Миниатюры используют собственное окно ±15 и могут прокручиваться независимо. Поле номера страницы внизу позволяет перейти в любую часть документа по Enter.
- Открытие старых документов Word `.doc` (97–2003) через преобразование в DOCX: редактирование, сохранение в DOCX и экспорт в PDF.
- Сворачивание панели комментариев кнопкой в её заголовке; открытие обратно кнопкой «Комментарии» справа.
- Масштабирование PDF и DOCX через `Ctrl+=`, `Ctrl++`, `Ctrl+−`, `Ctrl+колесо`; `Ctrl+0` возвращает 100%.
- Комментарии к PDF: заметки по щелчку, комментарии к выделенному тексту, редактирование и удаление.
- Выбор имени автора комментариев; создание копии PDF с теми же комментариями от другого имени.
- Базовое редактирование DOCX: текст, шрифты с поиском по названию, размер, жирный, курсив и подчёркивание.
- В палитрах цвета текста и маркера DOCX доступны «Другие цвета…» и «Пипетка»: тёмное окно с насыщенностью/яркостью, цветовым тоном, HEX/RGB, основными и 12 последними цветами. Пипетка берёт цвет с экрана; выбор применяется по кнопке «Применить», отмена не меняет документ. Снимок для пипетки используется только в памяти, не сохраняется и не отправляется.
- DOC/DOCX редактируется в постраничном режиме SuperDoc: отдельные листы, поля, линейка и перенос содержимого между страницами. Старые искусственные разрезы отключены. Движок виртуализирует окно на 5 страниц с запасом в одну; справа — список листов для перехода. Ctrl+Z сохраняет положение просмотра.
- Выравнивание текста, отступы слева, справа и первой строки.
- Таблицы в DOCX: создание, добавление и удаление строк и столбцов, удаление таблицы.
- Вставка таблиц с белой непрозрачной заливкой и чёрными границами; тот же стиль можно применить к текущей таблице.
- Для текстового выделения PDF доступна галочка «Ответ в комментарий» в плашке Gemini и в чате. Ответ остаётся в чате и добавляется к исходным словам как PDF-комментарий от выбранного автора (по умолчанию — имя пользователя Windows). Автор и выделение фиксируются при отправке. Ctrl+S сохраняет комментарий в файле, Ctrl+Z отменяет его добавление. При закрытии документа или изменении содержимого страницы комментарий не переносится на другой текст: ответ сохраняется в чате, причина показывается в статусе. Для DOCX ответы остаются только в чате.
- «Выбрать материал» в чате: отметь страницы кликом, добавь фотографии, затем переключайся между изображениями и отмечай задания красным пунктиром или кистью. Есть обрезка, отмена, очистка и удаление страницы. Для DOCX сначала готовится PDF текущих правок через LibreOffice. Разметка применяется к копиям; оригинал не меняется. «Прикрепить к чату» ничего не отправляет — изображения передаются в Gemini только вместе с вопросом по кнопке «Отправить».
- «Спросить ИИ»: выделенный текст PDF/DOCX и запрос отправляются в Google Gemini по API-ключу пользователя только по кнопке. Модель настраивается, ответ можно скопировать. Сохранение ключа опционально, с защитой Windows DPAPI.
- Сворачиваемый чат Gemini слева (кнопка ✦): вопросы и ответы, продолжение разговора, вопросы без выделения, остановка запроса и новый чат. После выделения PDF/DOCX у конца курсора появляется круглая кнопка Gemini с плашкой для вопроса; сам фрагмент в плашке и истории не показывается. Последние 10 пар успешных сообщений используются как контекст разговора, включая ранее отправленные фрагменты; «Новый чат» очищает контекст. История хранится только в памяти текущего запуска.
- Создание нового DOCX кнопкой «＋ DOCX» или `Ctrl+N`; первое сохранение предлагает выбрать имя файла.
- Правки PDF: вставка нового текста, поворот, добавление пустой страницы и удаление страниц. `Ctrl+Z` отменяет правки PDF и изменения комментариев в пределах текущей сессии.
- Локальный OCR для русского и английского текста. Результат появляется в отдельной карточке рядом с выделенной областью и доступен для копирования.
- Конвертация DOCX → PDF, PDF → DOCX / TXT, PDF → PNG и изображений → PDF.
- Создание PDF с распознанным текстовым слоем для поиска и копирования.
- Сохранение текущего документа по `Ctrl+S`, открытие PDF/DOCX через Windows «Открыть с помощью».
- Обычное выделение текста работает по умолчанию, когда инструменты выключены. Копирование: `Ctrl+C` или контекстное меню. OCR и комментарии отключаются повторным нажатием или `Esc`.
- Поиск по тексту через `Ctrl+F` в PDF с текстовым слоем, DOC и DOCX, подсветка и переход между совпадениями.

## Требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime для редактора DOC/DOCX. В установщик 1.1.0 он не включён.
- Свободное место для приложения, LibreOffice и моделей OCR.
- Для версии из исходников — интернет при первоначальной загрузке зависимостей и моделей.

Установщик включает **.NET 10 Desktop Runtime, LibreOffice, OCR-модели RU/EN и нативные библиотеки**. Отдельно устанавливать их не нужно. После установки обработка документов и распознавание работают локально; документы на сервер не отправляются. Переводчика в приложении нет.

Кнопка **⚙** на узкой панели слева открывает отдельные настройки API Gemini:
ключ, модель и сохранение ключа. Открывать документ или выделять текст для
настройки не требуется. Запрос в Google эта кнопка не отправляет.
Внутри настроек есть «Проверить ИИ»: она отправляет короткий тестовый запрос
с введёнными ключом и моделью. Сама проверка не сохраняет настройки.
Если выключить сохранение ключа, он остаётся доступен только в текущем
запуске приложения и после закрытия теряется.

Исключение — явно вызванная функция «Спросить ИИ»: для неё нужны интернет и
собственный Gemini API-ключ. В Google отправляются выбранный текст,
прикреплённые изображения и запрос вместе с контекстом чата. Ключ вводится в настройках API и не передаётся
в WebView. Если включить сохранение, настройки находятся в
`%LOCALAPPDATA%/ObsidianDocs/gemini.json`, а ключ зашифрован DPAPI текущего
пользователя Windows. Снятие флажка и сохранение настроек удаляет ключ из
сохранённых настроек. Получить ключ: https://aistudio.google.com/apikey.

В DOCX под панелью форматирования укажи число строк и столбцов и нажми
«＋ С границами и заливкой». «Оформить текущую таблицу» применяет белую заливку
и границы ко всей таблице, в которой стоит курсор. Эти свойства сохраняются
в DOCX; они не являются декоративной сеткой только для просмотра.

Материал для Gemini ограничен 12 изображениями за один выбор. Изображения
уменьшаются до 2200 пикселей по длинной стороне и отправляются как JPEG с
нанесённой разметкой; качество следует оценить в редакторе до отправки.
Изображения сохраняются в контексте текущего чата и повторно передаются при
продолжении разговора. Суммарно для истории допускается до 12 МБ изображений,
весь JSON-запрос ограничен 18 МБ; при превышении нужно убрать страницы или
начать новый чат. Отдельной загрузки файлов в Google Files API нет.

## Установка

1. Открой [последний релиз](https://github.com/Nextems/ObsiDopf/releases/latest).
2. Скачай файл `ObsiDopf-<версия>-Setup-x64.exe` и запусти его.
3. Оставь стандартную папку `%LOCALAPPDATA%\Programs\ObsiDopf` — для неё не нужны права администратора.
4. Выбери нужные ярлыки и регистрацию PDF/DOCX в «Открыть с помощью».

Для установки в `Program Files` запусти установщик от имени администратора. Регистрация форматов добавляет ObsiDopf в список приложений, но не меняет программу по умолчанию автоматически. Чтобы выбрать её самостоятельно: ПКМ по PDF или DOCX → **«Открыть с помощью» → «Выбрать другое приложение»** → ObsiDopf.

Размер установщика связан прежде всего с включённым LibreOffice и автономными зависимостями. Установщик пока без цифровой подписи. Удалить приложение можно через раздел установленных приложений Windows; пользовательские документы и профили авторов сохраняются.

## Использование

### Документы

Нажми **«Открыть»** или `Ctrl+O`. Открытые документы находятся во вкладках сверху. В PDF колёсико мыши прокручивает непрерывную ленту страниц; справа отображаются миниатюры. Кнопки **«Страницы»** и **«Комментарии»** управляют областью PDF-комментариев.

Кнопка **«›»** в заголовке комментариев сворачивает панель, кнопка **«Комментарии»** справа открывает её обратно. Для увеличения используй `Ctrl+=` или `Ctrl++`, для уменьшения — `Ctrl+−`; `Ctrl+колесо` меняет масштаб под курсором. Эти сочетания работают также в DOCX.

Для изменения PDF открой меню **«Правка PDF»**: можно добавить текст в выбранном месте, повернуть страницу, вставить пустую страницу после текущей или удалить текущую. Последнюю страницу удалить нельзя. Правки сначала меняют документ в памяти; `Ctrl+S` записывает их в файл. `Ctrl+Z` позволяет отменить недавние изменения, включая комментарии; история ограничена десятью снимками и объёмом памяти.

`Ctrl+S` сохраняет изменения прямо в текущий PDF или DOCX. `Ctrl+Shift+S` и **«Сохранить как…»** записывают документ под другим именем; этот файл становится текущим для следующих сохранений. **«Экспорт»** создаёт документ в другом формате.

### Комментарии PDF

Выбери **«Комментарий»**, щёлкни по странице, введи заметку и сохрани её. Для привязки к словам выбери **«Комментарий к тексту»**, выдели нужные слова мышью и напиши комментарий. Выделенный текст подсвечивается, заметка отображается в боковой панели.

Открыть заметку для изменения можно через её значок на странице или список комментариев. Кнопка **«Удалить»** есть в списке и в карточке заметки. После изменений нажми `Ctrl+S`, чтобы записать их в PDF.

По умолчанию используется имя пользователя Windows. В панели комментариев можно выбрать другое сохранённое имя или добавить своё. **«Создать копию от этого имени…»** сохраняет отдельный PDF с теми же комментариями и новым автором. Оригинал остаётся без изменений.

### Редактор DOCX

Старые файлы **DOC** при первом открытии локально преобразуются LibreOffice в **DOCX** и открываются в том же редакторе: можно редактировать текст и таблицы, выделять и копировать текст, искать по `Ctrl+F`. Промежуточный PDF не создаётся. Первый `Ctrl+S` предлагает сохранить отдельный `.docx`; исходный DOC не перезаписывается. Через **«Экспорт»** можно записать DOCX или создать PDF с текущими правками. Преобразованный DOCX хранится в `%LOCALAPPDATA%\ObsidianDocs\doc-to-docx` и повторно используется, пока исходный файл и движок не изменились. Первое преобразование всё ещё может занять время; индикатор показывает прошедшее время, кнопка **«Отменить»** или `Esc` останавливает процесс. Кэш ограничен по размеру и количеству файлов. Сложное оформление может отличаться от Word; действуют ограничения базового редактора DOCX.

DOCX открывается напрямую, без предварительного преобразования в PDF. Выдели текст и используй панель форматирования: шрифт, размер, начертание и выравнивание. В поле шрифта можно ввести часть названия и выбрать результат; `Enter` применяет его. Размер задаётся в пунктах, отступы — в сантиметрах с применением по `Enter`.

Чтобы создать документ с нуля, нажми **«＋ DOCX»** или `Ctrl+N`. Первый `Ctrl+S` открывает выбор имени и папки, последующие сохранения записывают изменения в выбранный DOCX.

Для новой таблицы укажи количество строк и столбцов рядом с **«＋ Таблица»**. Чтобы изменить существующую, поставь курсор в её ячейку и выбери действие со строкой или столбцом. `Ctrl+Z` отменяет правки, `Ctrl+Y` повторяет отменённые действия. Инструменты PDF-комментариев в DOCX скрыты.

### Распознавание текста

Когда инструменты выключены, просто выдели слова мышью и нажми `Ctrl+C` либо выбери **«Копировать»** правой кнопкой мыши. Повторное нажатие активного инструмента OCR или комментариев выключает его и возвращает обычное выделение; `Esc` также отключает инструмент. В DOCX используется штатное выделение редактора. На фотографии или скане без текстового слоя сначала нужен OCR.

Для поиска нажми `Ctrl+F` и введи текст. Поиск не учитывает регистр; `Enter` / `F3` и стрелка вниз переходят к следующему совпадению, `Shift+Enter` / `Shift+F3` и стрелка вверх — к предыдущему. В PDF и DOC/DOCX совпадения подсвечиваются жёлтым, активное — оранжевым. `Esc` закрывает строку поиска. Для скана сначала создай PDF с OCR-слоем.

1. Открой PDF, фотографию или скан.
2. Выбери **RU** или **EN**, нажми **«OCR области»**.
3. Выдели прямоугольную область мышью.
4. Скопируй результат из карточки справа от выделения или нажми **«Копировать всё»**.

В карточке можно поправить распознанный текст или повторить распознавание. `Escape` закрывает её. Для создания документа с поиском выбери экспорт в **PDF с текстовым слоем OCR**.

## Ограничения

- Постраничный редактор DOCX использует собственный движок SuperDoc, а экспорт PDF — LibreOffice. Сложные документы могут отличаться от Microsoft Word и экспортируемого PDF. Новая интеграция пока собрана без ручного запуска и проверки документов.
- Собственный код ObsiDopf лицензируется по AGPL-3.0-only; SuperDoc 1.47.2 сохраняет свою AGPL-лицензию. Полный архив исходников движка и наших изменений подготовлен отдельно; до публичного выпуска остаётся сверка уведомлений компонентов. Подробнее: [исходники SuperDoc](packaging/superdoc/SOURCE-INFO.md).
- PDF → DOCX переносит текст с разделением по страницам, без восстановления исходной верстки и изображений. Страницы без текстового слоя распознаются OCR.
- Экспорт в PDF с OCR создаёт копию из изображений страниц. Интерактивные формы, ссылки и комментарии в неё не переносятся; обычное сохранение PDF сохраняет комментарии.
- Редактирование существующего текста PDF не реализовано. Комментарии к словам требуют текстового слоя; для скана сначала создай PDF с OCR.
- Для OCR заявлены русский и английский языки. Качество зависит от резкости изображения, размера и языка текста.

## Запуск из исходников

Нужны **.NET 10 SDK**, **Node.js 22+**, **Rust stable** и **Visual Studio Build Tools** с компонентом **Desktop development with C++** и Windows SDK. MSBuild автоматически подготавливает локальные JS/CSS редактора Word из зафиксированной npm-зависимости; Node.js при запуске приложения не нужен.

```powershell
git clone https://github.com/Nextems/ObsiDopf.git
cd ObsiDopf
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
.\start.bat
```

Первый запуск сборки подготовит локальный LibreOffice и соберёт Rust OCR worker. Модели OCR загружаются при первом распознавании в `%USERPROFILE%\.oar`; последующее распознавание работает из кэша. Для экспорта через установленный LibreOffice можно задать путь к `soffice.com` переменной `OBSIDIAN_DOCS_SOFFICE`; сборочные скрипты подготавливают собственную копию движка.

Для повторной сборки только C# используй `build.ps1 -SkipRust`. Каждая сборка создаёт отдельную папку в `releases/`, а `start.bat` открывает версию из `current-build.txt`.

Сборка автономного установщика:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build-installer.ps1 -Version 1.1.0
powershell -NoProfile -ExecutionPolicy Bypass -File packaging/package-release-source.ps1 -Version 1.1.0
```

Перед упаковкой модели OCR и их контрольные суммы должны находиться в кэше RU/EN. Результат: установщик `dist/ObsiDopf-1.1.0-Setup-x64.exe`, архив текущих исходников, описание релиза и SHA-256. Для повторного использования неизменённых OCR/LibreOffice из прежней установки у `build-installer.ps1` есть параметр `-ComponentsRoot` с её абсолютным путём. В Git хранятся исходники; установщики публикуются в [Releases](https://github.com/Nextems/ObsiDopf/releases) после решения вопросов распространения нового движка.

Архив движка `ObsiDopf-1.1.0-SuperDoc-1.47.2-Source.zip` подготавливает
`packaging/superdoc/prepare-source.ps1`; общий скрипт упаковки исходников вызывает его
при необходимости. Для подготовки только исходников, без включения старого установщика
в новый набор контрольных сумм: `packaging/package-release-source.ps1 -SourcesOnly`.
Оба архива исходников нужно публиковать с соответствующим установщиком.
