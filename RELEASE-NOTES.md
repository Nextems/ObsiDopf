# ObsiDopf 1.1.0-r2

Обновление для Windows 10/11 x64 от 22 ноября 2026 года.
Тег выпуска — `v1.1.0-r2`. В метаданных программы и установщика сохранена версия 1.1.0.

## Новое

- Слева добавлена кнопка ▦ «Глобальные действия».
- Массовая смена авторов комментариев в выбранных PDF: выбор файлов или добавление открытых PDF, имя автора и сохранение копий в выбранную папку либо изменение оригиналов. При экспорте в другую папку сохраняются также PDF без комментариев и файлы, где автор уже совпадает; их исходные байты не изменяются. Сохраняются тексты, выделения, координаты и даты комментариев. Несохранённые правки в открытых документах защищены.
- Глобальная конвертация смешанного списка PDF, DOCX и DOC. Формат выбирается автоматически: PDF → DOCX, DOC/DOCX → PDF. Есть выбор папки результатов, добавление открытых документов, прогресс, остановка и результат для каждого файла. Совпадающие имена получают числовой суффикс; существующие файлы не перезаписываются. Ошибка отдельного файла не прерывает остальные.
- PDF → DOCX переносит текст с разделением по страницам. Страницы без текстового слоя обрабатываются локальным OCR с выбором русского или английского языка. Исходная вёрстка, изображения и комментарии в DOCX не переносятся.
- Значки комментариев PDF можно перетаскивать в пределах страницы. `Esc` отменяет перетаскивание, `Ctrl+Z` отменяет завершённый перенос, `Ctrl+S` сохраняет положение. Для комментариев к тексту выделение остаётся привязанным к словам. Положение их значка хранится в данных ObsiDopf; обычные заметки перемещаются также в других PDF-просмотрщиках.

Сохранены функции предыдущего выпуска: постраничный редактор DOC/DOCX SuperDoc, поиск, таблицы, расширенная палитра и пипетка, история документов, вкладки, PDF-комментарии и выделения, OCR и чат Gemini.

## Установка

1. Закройте работающий ObsiDopf перед обновлением.
2. Запустите `ObsiDopf-1.1.0-Setup-x64.exe`. Предпочтительна предлагаемая папка текущего пользователя в LocalAppData.
3. Для редактора DOC/DOCX нужен Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/. Он не включён в установщик.
4. Для Gemini укажите собственный API-ключ. Выделенный текст и изображения отправляются только при явно вызванной отправке в чат.

.NET Runtime, OCR-модуль, модели RU/EN и LibreOffice включены. Конвертация и OCR работают локально. Ключи API, профили авторов и пользовательские документы в установщик не входят.

## Проверки

Добавлены проверки массовой смены авторов, копирования неизменённых PDF, направлений конвертации, OCR-маршрута, конфликтов имён, отмены и очистки временных файлов. Проверки переноса комментариев охватывают сохранение и повторное открытие PDF, отмену, границы страницы, CropBox и повороты 0/90/180/270°, сохранение текстовых выделений и внешнего вида аннотаций.

Отчёт `ObsiDopf-1.1.0-Validation.json`, если приложен к выпуску, содержит результаты проверок именно опубликованного установщика и его SHA-256: установка в отдельную папку, контрольные суммы файлов, автономный запуск, OCR RU/EN, DOCX → PDF, редактор Word, PDF-комментарии, Ctrl+S, прокрутка и удаление с сохранением пользовательского файла. Gemini API с пользовательским ключом и точность выбора экранного пикселя пипеткой не проверяются.

## Ограничения

- Разметка сложных DOC/DOCX может отличаться от Microsoft Word и экспортированного PDF; большие документы могут задерживаться при редактировании.
- Редактирование существующего текста PDF не реализовано.
- PDF → DOCX выполняет текстовую конвертацию, без восстановления исходной вёрстки и изображений.
- Несохранённые открытые документы пропускаются в глобальных действиях — сначала сохраните их.
- Установщик не подписан цифровой подписью.
